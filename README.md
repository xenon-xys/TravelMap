### 项目初衷

每一趟旅途都是独一无二的珍贵回忆，每个人都在用自己的方式留存旅行瞬间：相册地图、照片墙、主流地图软件足迹、热门的“中国制霸”打卡模式等。

但市面上各类旅行记录工具，普遍存在操作不便、定位不准、行政区划粒度粗糙等问题，无法精准匹配个人真实旅行轨迹。

本项目以**中国制霸**为设计蓝本，打造以**地级行政区**为核心统计单位的精细化旅行足迹地图，精准记录每一次出行，完整留存你的旅途印记。

> *注：地图区划边界以国家官方底图为基准，仅做轻微边缘锐化处理，边界线条仅供参考，官方区划标准请以国家发布数据为准。*

## ✨ 核心特色

### 1\. 超全行政区划覆盖

全覆盖国内各级行政区，统计维度细致全面，适配全场景旅行打卡记录：

- 包含 **333 个地级行政区**

- 包含 **4 个直辖市**、**2 个特别行政区**

- 收录海南、湖北、河南、新疆共计 **32 个省直辖县级行政区**（未计入2026年最新设立的新疆草湖县级市）

- 适配台湾省 **6\+3\+13** 专属行政区划体系

### 2\. 精细化出行状态分类

优化传统出行标签，贴合真实出行场景，精准区分旅行状态，告别笼统记录：

原分类 → 优化后精准分类：**居住 / 过夜游 / 一日游 / 停留 / 经过 / 未去过**

### 3\. 高效便捷标记体验

- **连续标记功能**：支持画笔批量标记多个城市，无需单点重复操作，高效批量记录行程

- **精准搜索定位**：陌生地区、小众城市可直接搜索定位，快速锁定目标行政区，解决地图难找地点问题

- **双指缩放查看**：移动端支持缩放地图，清晰查看各地地名与区划范围

### 4\. 个性化展示与分享

- 支持**自定义背景图**，打造专属个性化旅行地图

- 可生成**无字版纯净地图**，方便朋友圈、社交平台分享展示

### 5\. 数据统计与成就系统

内置完整成就统计体系，自动计算旅行数据：已点亮行政区数量、旅行覆盖率、综合得分等，可视化展示你的旅行版图。

### 6\. 数据备份说明

网页端数据仅保存在当前浏览器本地，**更换设备、清除浏览器缓存会导致数据丢失**。支持导出 JSON 备份文件，可跨设备导入恢复数据，永久留存旅行记录。
